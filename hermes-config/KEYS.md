# Ключи в этом экспорте — НЕ ХРАНЯТСЯ

Экспорт скиллов и конфига в этом репозитории **очищен от секретов**: реальные API-ключи
(NVIDIA `nvapi-*`, `sk-*` и прочие) заменены на `<REDACTED_в_экспорте>`.

Причина: скиллы `devops/repair-api-keys` и `hermes/hermes-api-key-rotation` содержали
рабочие ключи в открытом виде. В git (даже приватный) они не попадают.

## Откуда берутся ключи при восстановлении

| Провайдер | Источник | Как восстановить |
|---|---|---|
| `nvidia` | `env:NVIDIA_API_KEY` + `~/.hermes/auth.json` | ключ из `~/LLM-API-KEYS.md` (внешний носитель) или из бэкапа `~/.hermes/auth.json` |
| остальные | `~/.hermes/auth.json` | `hermes auth add <provider> <key>` |

`~/.hermes/auth.json` в git не кладём — он лежит:
1. в бэкапе на внешнем диске `/run/media/thomas/F2DB-14E5/`,
2. в `~/LLM-API-KEYS.md` (перечень ключей по провайдерам).

Проверка после восстановления:

```bash
hermes auth list          # все нужные провайдеры с priority
hermes auth doctor        # если доступно
```

Скилл `devops/repair-api-keys` в этом экспорте сохранён как **процедура** (какие ключи
и в каком порядке заливать), без самих значений.
